SCHOL0MANCE RUNS — iPhone

Как установить:
1. Размести содержимое этой папки на любом статическом HTTPS-хостинге.
   Самый простой вариант: GitHub Pages, Netlify или Cloudflare Pages.
2. Открой ссылку на iPhone в Safari.
3. Нажми «Поделиться».
4. Выбери «На экран Домой».
5. После этого приложение появится отдельной иконкой.

Важно:
- История хранится локально в Safari на этом iPhone.
- Если очистить данные Safari, история может удалиться.
- Работает офлайн после первого успешного открытия.
